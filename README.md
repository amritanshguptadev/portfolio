# 3D Developer Portfolio

This is a premium, interactive 3D Developer Portfolio built with React, Three.js (React Three Fiber), and Tailwind CSS, featuring custom magnetic cursors, smooth scroll progress indicators, cinematic route transitions, and floating 3D geometry.

## 🌐 Live Demo & Repository

- **GitHub Repository**: [https://github.com/amritanshguptadev/portfolio.git](https://github.com/amritanshguptadev/portfolio.git)

## 📝 Features

- **Interactive 3D Elements**: Smooth, responsive 3D floating shapes and structures.
- **Custom Magnetic Cursor**: A glowing ring cursor that trails the mouse pointer and magnetizes to interactive buttons.
- **Scroll Progress Bar**: A sleek gold-to-violet gradient progress bar indicating read depth.
- **Cinematic Route Transitions**: Clean overlay wipes that smooth out page changes.
- **Responsive Layout**: Designed to look stunning on both desktop monitors and touch/mobile devices.
- **Detailed Pages**: Interactive About, Projects, Skills, and Journey timelines.

## 🧰 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Ensure you have the following installed:
- Node.js (v18 or higher recommended)
- npm or yarn
- Git

### Installation & Local Run

1. Clone the repository:
   ```bash
   git clone https://github.com/amritanshguptadev/portfolio.git
   ```

2. Navigate into the directory and install dependencies:
   ```bash
   cd portfolio
   npm install
   ```

3. Configure your environment variables. Create a `.env` file in the root directory and add your EmailJS configuration:
   ```env
   VITE_EMAILJS_SERVICE_ID=your_service_id
   VITE_EMAILJS_TEMPLATE_ID=your_template_id
   VITE_EMAIL_JS_ACCESS_TOKEN=your_access_token
   ```

4. Start the local development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`.

## 📜 Build Scripts

- `npm run dev`: Starts the local development server.
- `npm run build`: Compiles the TypeScript and builds the production site in `./dist/`.
- `npm run preview`: Previews the built production site locally.
- `npm run lint`: Runs ESLint check.
- `npm run ts:check`: Checks TypeScript types.
